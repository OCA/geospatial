Show the image of the records picked as value of a geo condition in the
search bar, e.g. the logo or flag of a region.

The standard record selector only shows the avatar of a fixed list of
models (contacts, users, employees). This module shows an image for
every reference model of the geo search that has one: it uses the first
field of *logo*, *image_128* or *avatar_128* that the model defines.

Configuration
=============

Nothing to configure: the image field of a reference model is detected
automatically from the fields *logo*, *image_128* or *avatar_128*.
